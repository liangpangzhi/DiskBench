Disk Bench 二次开发 · 坏道屏蔽功能

把扫描中确认的坏道记录为屏蔽表，扫描时跳过这些区间，避免反复读取坏道触发磁盘错误恢复（可能长时间卡住）。以下是界面效果与实际接口返回。

屏蔽区以灰白斜纹表示：本次扫描刻意跳过，不计入“已测试”，也不产生读错误。

③ 异常明细 · 一键屏蔽

扫描结果的“异常明细”中新增 屏蔽严重坏道 按钮，一键把不可读/设备错误坏道加入屏蔽表。

✓ 已加入屏蔽表 1 个区间，可在磁盘详情的“坏道屏蔽”中查看

④ 实际接口返回（mock 服务实测）

GET /api/blocklist?device=/dev/sda → {"blocklist":{"ranges":[]}}
POST /api/blocklist 添加 2 区间 → 返回合并后的 ranges
DELETE /api/blocklist?device=/dev/sda&offset=0&length=4096 → 删除单区间
POST /api/jobs/{id}/mask {"filter":"severe"} → {"added":1,"blocklist":{...}}
安全校验：写操作缺少 X-Requested-With: DiskBench → 403；非法设备路径 → 400。
扫描异常记录→一键屏蔽 / 手动添加→按磁盘持久化屏蔽表→扫描时跳过→块图标记“已屏蔽”
